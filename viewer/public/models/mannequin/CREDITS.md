# CesiumMan.glb

The rigged, skinned figure the third-person mannequin uses (`src/rig.ts`).

- **Title:** Cesium Man (glTF Sample Assets, `Models/CesiumMan/glTF-Binary/CesiumMan.glb`)
- **Author:** Cesium, 2017
- **Licence:** [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/legalcode)
- **Source:** https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CesiumMan
- **Changes:** none to the file. It is posed at run time by our own inverse kinematics (`src/rig.ts`); the original walk animation is not played.
- **Note:** the model's texture carries Cesium's logo, which is a Cesium trademark and is not covered by the licence (the sample-asset README flags it as a non-Khronos mark).
- **Not a person's measurements:** the figure is stylised (short legs and arms for its height); it stands in for the user in the 3D view and measures nothing.
